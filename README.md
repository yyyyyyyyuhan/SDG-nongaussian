## Sparse dynamic graphical models for longitudinal non-Gaussian data 

This repository provides R implementations of sparse dynamic graphical models for longitudinal non-Gaussian data, including binary, count, and compositional outcomes. The framework uses a latent Gaussian vector autoregressive process to characterize temporal associations and contemporaneous conditional dependence in multivariate repeated measurements.
The repository includes data generators, estimation functions, simulation scripts, and a longitudinal microbiome application using data from the Human Microbiome Project 2 (HMP2).

## Project Structure

- `R/` — Core method implementations for three non-gaussian outcomes.
- `sim/` — Simulation scripts for binary, counts, compositional outcomes.
- `plots/` — Plotting scripts.
- `data/` — Raw data, processed data and codes for Human Microbiome Project (HMP2).
- `results/` — Output figures for temporal dependence matrix and comtemporaneous conditional dependence matrix.
