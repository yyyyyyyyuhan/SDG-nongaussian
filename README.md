# Project Name

Comparison of Θ and Γ recovery 
across different graphical structures and outcome types.

## Project Structure

- `R/` — Core method implementations (estimation, evaluation functions)
- `simulations/` — Simulation scripts for binary, Poisson, multinomial outcomes
- `scripts/` — Plotting and analysis scripts
- `data/` — Raw and processed data
- `results/` — Output tables and figures
- `paper/` — Manuscript files
- `docs/` — Additional documentation
